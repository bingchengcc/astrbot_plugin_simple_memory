插件工程方案

## 一、概述

**目标**：把 OpenClaw workspace 的记忆文件（MEMORY.md、SOUL.md、memory/*.md）和 AstrBot 自己的对话记录统一进本地向量库，提供两路能力：
1. **被动注入**：每次 LLM 请求前，把 MEMORY.md / SOUL.md 拼进 system prompt
2. **主动检索**：注册 `memory_search` LLM 工具，Agent 按需调用

**技术栈**：
- Embedding：Qwen3-Embedding-0.6B，sentence-transformers 加载，常驻内存，`asyncio.to_thread` 包推理避免阻塞事件循环
- 向量库：Chroma PersistentClient，cosine 距离，数据存 `data/plugin_data/astrbot_plugin_openclaw_memory/chroma/`（官方规范：持久化数据放 data 目录，防插件更新覆盖）
- 文件监听：watchdog，2 秒防抖，防写一半被读
- 切块：Markdown 按标题/段落切，384 token 目标 + 64 token 重叠

**已校对的 API 版本点**（跟你 skill 文档的出入）：
| 项 | Skill 写法 | 正确写法（源码+官方wiki） |
|---|---|---|
| 工具注册 | `StarTools.register_llm_tool` | `@filter.llm_tool` 装饰器 或 `@dataclass FunctionTool` + `context.add_llm_tools()`（前者更适合本场景，因为工具要读插件内状态） |
| 构造函数 | `(context, config: AstrBotConfig)` | `(context: Context, config: dict \| None = None)` |
| 生命周期 | `shutdown()` | `terminate()`（Star 基类定义） |
| 数据目录 | 插件目录内 | `StarTools.get_data_dir()` → `data/plugin_data/{name}/` |
| logger | `logging.getLogger` | `from astrbot.api import logger` |
| 网络库 | requests | httpx/aiohttp（本插件基本不联网，仅首次下模型） |

from pathlib import Path


class MemoryFiles:
    ROOT_FILES = ["MEMORY.md", "SOUL.md", "TOOLS.md"]

    def __init__(self, workspace: Path):
        self.workspace = workspace

    def list_memory_files(self) -> list[Path]:
        result: list[Path] = []
        for name in self.ROOT_FILES:
            p = self.workspace / name
            if p.is_file():
                result.append(p)
        mem_dir = self.workspace / "memory"
        if mem_dir.is_dir():
            result.extend(sorted(mem_dir.rglob("*.md")))
        return result

    def read(self, path: Path) -> str:
        return path.read_text(encoding="utf-8", errors="ignore")

    def rel(self, path: Path) -> str:
        return path.relative_to(self.workspace).as_posix()

### memory_store/chunker.py

```python
from __future__ import annotations
import re
from collections.abc import Callable


class Chunker:
    def __init__(self, size: int = 384, overlap: int = 64):
        self.size = size
        self.overlap = overlap

    def split(self, text: str, count_tokens: Callable[[str], int]) -> list[str]:
        paragraphs = self._split_paragraphs(text)
        chunks: list[str] = []
        buf = ""
        for p in paragraphs:
            while count_tokens(p) > self.size:
                if buf:
                    chunks.append(buf)
                    buf = self._tail(buf)
                cut = self._hard_cut(p, count_tokens)
                chunks.append(cut)
                p = p[len(cut) - self.overlap_chars(cut, count_tokens):] if count_tokens(p) > self.overlap else ""
            candidate = f"{buf}\n\n{p}" if buf else p
            if count_tokens(candidate) <= self.size:
                buf = candidate
            else:
                chunks.append(buf)
                buf = self._tail(p)
        if buf.strip():
            chunks.append(buf)
        return [c.strip() for c in chunks if c.strip()]

    def _split_paragraphs(self, text: str) -> list[str]:
        parts = re.split(r"\n(?=#{1,6} )|\n{2,}", text)
        return [p.strip() for p in parts if p.strip()]

    def _hard_cut(self, text: str, count_tokens: Callable[[str], int]) -> str:
        lo, hi = 1, len(text)
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if count_tokens(text[:mid]) <= self.size:
                lo = mid
            else:
                hi = mid - 1
        return text[:lo]

    def _tail(self, text: str, count_tokens=None) -> str:
        if count_tokens is None:
            return text[-120:]
        keep, start = 0, len(text)
        lo, hi = 0, len(text)
        while lo < hi:
            mid = (lo + hi) // 2
            if count_tokens(text[mid:]) <= self.overlap:
                start = mid
                hi = mid
            else:
                lo = mid + 1
        return text[start:]

    def overlap_chars(self, text: str, count_tokens) -> int:
        return len(text) - self._tail(text, count_tokens).find(text) + len(text)
```

> 实现提示：`_tail` 二分找重叠尾部，硬切用二分逼近 token 上限。第一个版本可以先不追求完美重叠，把 `overlap` 简化为固定字符数 160，跑通后再优化。

### memory_store/embedder.py

```python
import asyncio


class Embedder:
    def __init__(self, model_name: str, device: str = "auto"):
        self.model_name = model_name
        self.device = device
        self.model = None

    async def load(self):
        await asyncio.to_thread(self._load_sync)

    def _load_sync(self):
        import torch
        from sentence_transformers import SentenceTransformer

        if self.device == "auto":
            device = "cuda" if torch.cuda.is_available() else "cpu"
        else:
            device = self.device
        self.model = SentenceTransformer(self.model_name, device=device)
        self.model.tokenizer.padding_side = "left"

    def count_tokens(self, text: str) -> int:
        return len(self.model.tokenizer.encode(text, add_special_tokens=False))

    async def embed(self, texts: list[str]) -> list[list[float]]:
        if not texts:
            return []
        return await asyncio.to_thread(self._embed_sync, texts)

    def _embed_sync(self, texts: list[str]) -> list[list[float]]:
        vecs = self.model.encode(
            texts, normalize_embeddings=True, batch_size=16, show_progress_bar=False
        )
        return vecs.tolist()

    async def unload(self):
        self.model = None
```

### memory_store/vector_db.py

```python
import hashlib


class VectorDB:
    COLLECTION = "openclaw_memory"

    def __init__(self, path: str):
        self.path = path
        self.col = None

    def init(self):
        import chromadb

        client = chromadb.PersistentClient(path=self.path)
        self.col = client.get_or_create_collection(
            self.COLLECTION, metadata={"hnsw:space": "cosine"}
        )

    @staticmethod
    def chunk_id(file: str, idx: int) -> str:
        return hashlib.md5(f"{file}#{idx}".encode()).hexdigest()

    def delete_file(self, file: str) -> None:
        try:
            self.col.delete(where={"file": file})
        except Exception:
            pass

    def upsert(self, ids: list[str], embeddings, texts: list[str], metas: list[dict]) -> None:
        self.col.upsert(ids=ids, embeddings=embeddings, documents=texts, metadatas=metas)

    def query(self, emb: list[float], n: int = 5, where: dict | None = None) -> dict:
        return self.col.query(
            query_embeddings=[emb],
            n_results=n,
            where=where,
            include=["documents", "metadatas", "distances"],
        )

    def count(self) -> int:
        return self.col.count()
```

> 注意：Chroma metadata 值只支持 str/int/float/bool，timestamp 用 int（unix 秒），过滤条件走简单等值查询，时间范围在后处理过滤。

### memory_store/searcher.py

```python
import re
import time
from dataclasses import dataclass


@dataclass
class SearchHit:
    text: str
    source: str
    file: str
    timestamp: int
    score: float


class Searcher:
    def __init__(self, vdb, embedder):
        self.vdb = vdb
        self.embedder = embedder

    async def search(self, query: str, source: str = "all", time_range: str = "", top_k: int = 5) -> list[SearchHit]:
        if not query.strip():
            return []
        q_emb = await self.embedder.embed([query])
        where = {"source": source} if source in ("openclaw", "astrbot") else None
        raw = self.vdb.query(q_emb[0], n=top_k * 3, where=where)

        cutoff = self._parse_range(time_range)
        hits: list[SearchHit] = []
        seen: set[str] = set()
        ids = raw.get("ids", [[]])[0]
        docs = raw.get("documents", [[]])[0]
        metas = raw.get("metadatas", [[]])[0]
        dists = raw.get("distances", [[]])[0]
        for i, doc in enumerate(docs):
            meta = metas[i] or {}
            ts = int(meta.get("timestamp", 0))
            if cutoff and ts < cutoff:
                continue
            key = f"{meta.get('file', '')}#{doc[:64]}"
            if key in seen:
                continue
            seen.add(key)
            hits.append(SearchHit(
                text=doc,
                source=meta.get("source", "unknown"),
                file=meta.get("file", ""),
                timestamp=ts,
                score=round(1.0 - float(dists[i]), 4) if i < len(dists) else 0.0,
            ))
            if len(hits) >= top_k:
                break
        return hits

    @staticmethod
    def _parse_range(time_range: str) -> int:
        m = re.fullmatch(r"(\d+)([mhdw])", (time_range or "").strip().lower())
        if not m:
            return 0
        n, unit = int(m.group(1)), m.group(2)
        factor = {"m": 60, "h": 3600, "d": 86400, "w": 604800}[unit]
        return int(time.time()) - n * factor
```

### watcher.py

```python
import asyncio
import logging
from pathlib import Path
from typing import Awaitable, Callable

logger = logging.getLogger("astrbot")


class FileWatcher:
    def __init__(
        self,
        watch_dir: Path,
        on_change: Callable[[Path], Awaitable[None]],
        debounce_s: float = 2.0,
    ):
        self.watch_dir = watch_dir
        self.on_change = on_change
        self.debounce_s = debounce_s
        self._observer = None
        self._timers: dict[str, asyncio.TimerHandle] = {}
        self._loop: asyncio.AbstractEventLoop | None = None

    def start(self) -> None:
        from watchdog.events import FileSystemEventHandler
        from watchdog.observers import Observer

        self._loop = asyncio.get_running_loop()
        watcher_self = self

        class _Handler(FileSystemEventHandler):
            def _touch(self, path_str: str):
                p = Path(path_str)
                if p.suffix.lower() != ".md" or not p.is_file():
                    return
                key = str(p)
                if key in watcher_self._timers:
                    watcher_self._timers[key].cancel()
                watcher_self._timers[key] = self._loop.call_later(
                    watcher_self.debounce_s, watcher_self._fire, p
                )

            def on_modified(self, event):
                if not event.is_directory:
                    self._touch(event.src_path)

            def on_created(self, event):
                if not event.is_directory:
                    self._touch(event.src_path)

        self._observer = Observer()
        self._observer.schedule(_Handler(), str(self.watch_dir), recursive=True)
        self._observer.daemon = True
        self._observer.start()

    def _fire(self, path: Path) -> None:
        self._timers.pop(str(path), None)
        asyncio.run_coroutine_threadsafe(self._safe(path), self._loop)

    async def _safe(self, path: Path) -> None:
        try:
            await self.on_change(path)
        except Exception:
            logger.exception(f"watcher 处理 {path} 失败")

    def stop(self) -> None:
        if self._observer:
            self._observer.stop()
            self._observer.join(timeout=5)
            self._observer = None
```

### ingest.py

```python
import asyncio
import time

from astrbot.api import logger


class ConversationIngestor:
    def __init__(self, context, embedder, vdb, chunker):
        self.context = context
        self.embedder = embedder
        self.vdb = vdb
        self.chunker = chunker
        self.queue: asyncio.Queue = asyncio.Queue()
        self._task: asyncio.Task | None = None

    def start(self) -> None:
        self._task = asyncio.create_task(self._worker())

    async def stop(self) -> None:
        if self._task:
            self._task.cancel()

    async def enqueue(self, session_id: str, user_text: str, ai_text: str) -> None:
        text = f"Q: {user_text}\nA: {ai_text}"
        await self.queue.put((session_id, text))

    async def _worker(self) -> None:
        while True:
            session_id, text = await self.queue.get()
            try:
                await self._ingest(session_id, text)
            except asyncio.CancelledError:
                raise
            except Exception:
                logger.exception("对话入库失败")

    async def _ingest(self, session_id: str, text: str) -> None:
        if not text.strip():
            return
        file_key = f"conversation:{session_id}"
        chunks = self.chunker.split(text, self.embedder.count_tokens)
        if not chunks:
            return
        embs = await self.embedder.embed(chunks)
        now = int(time.time())
        self.vdb.upsert(
            ids=[self.vdb.chunk_id(file_key, i) for i in range(len(chunks))],
            embeddings=embs,
            texts=chunks,
            metas=[{"file": file_key, "source": "astrbot", "timestamp": now} for _ in chunks],
        )
        logger.info(f"对话入库 {len(chunks)} 块 <- {session_id}")
```

> 说明：每轮对话作为独立 file_key 增量 upsert，不 delete 整个 session（避免锁竞争和全量重写）。session 数量增长后可加定期合并逻辑，v1 不做。

### main.py

```python
import time
from pathlib import Path
from typing import Any

from astrbot.api import logger
from astrbot.api.event import AstrMessageEvent, filter
from astrbot.api.provider import ProviderRequest
from astrbot.api.star import Context, Star, StarTools
from astrbot.core.star.register import on_agent_done, on_llm_request

from .ingest import ConversationIngestor
from .memory_store.chunker import Chunker
from .memory_store.embedder import Embedder
from .memory_store.files import MemoryFiles
from .memory_store.searcher import Searcher
from .memory_store.vector_db import VectorDB
from .watcher import FileWatcher

INJECT_MARKER = "\n# Memory Context\n\n"


class OpenClawMemory(Star):
    def __init__(self, context: Context, config: dict | None = None):
        super().__init__(context, config)
        cfg = config or {}
        self.cfg = cfg
        self.enabled: bool = cfg.get("enabled", True)
        self.workspace: Path = Path(cfg.get("workspace_path", "") or "")
        self.chunker = Chunker(
            size=int(cfg.get("chunk_size", 384)),
            overlap=int(cfg.get("chunk_overlap", 64)),
        )
        self.files = MemoryFiles(self.workspace)
        self.embedder: Embedder | None = None
        self.vdb: VectorDB | None = None
        self.searcher: Searcher | None = None
        self.watcher: FileWatcher | None = None
        self.ingestor: ConversationIngestor | None = None
        self.inject_text = ""
        self._index_lock = asyncio.Lock()

    # ---------- 生命周期 ----------

    async def initialize(self) -> None:
        if not self.enabled or not str(self.workspace).strip():
            logger.info("openclaw_memory 未启用或未配置 workspace_path")
            return
        if not self.workspace.is_dir():
            logger.warning(f"workspace 不存在: {self.workspace}")
            return

        import asyncio  # noqa: F401  (顶部 import 更规范，此处防读者漏看)

        self._index_lock = asyncio.Lock()

        self.embedder = Embedder(
            model_name=self.cfg.get("embedding_model", "Qwen/Qwen3-Embedding-0.6B"),
            device=self.cfg.get("device", "auto"),
        )
        logger.info("加载 embedding 模型...")
        await self.embedder.load()

        vdb_path = self.cfg.get("vector_db_path") or str(StarTools.get_data_dir() / "chroma")
        self.vdb = VectorDB(vdb_path)
        self.vdb.init()

        self.searcher = Searcher(self.vdb, self.embedder)
        await self._reindex_all()
        self._refresh_inject()

        self.watcher = FileWatcher(self.workspace, on_change=self._on_md_changed)
        self.watcher.start()

        if self.cfg.get("ingest_conversations", True):
            self.ingestor = ConversationIngestor(self.context, self.embedder, self.vdb, self.chunker)
            self.ingestor.start()

        logger.info(f"openclaw_memory 启动完成，索引 {self.vdb.count()} 块")

    async def terminate(self) -> None:
        if self.watcher:
            self.watcher.stop()
        if self.ingestor:
            await self.ingestor.stop()
        if self.embedder:
            await self.embedder.unload()
        logger.info("openclaw_memory 已停止")

    @staticmethod
    def info() -> dict[str, Any]:
        return {
            "name": "astrbot_plugin_openclaw_memory",
            "author": "tuan",
            "description": "OpenClaw 记忆系统：本地向量检索 + system prompt 注入",
            "version": "0.1.0",
        }

    # ---------- 索引 ----------

    async def _reindex_all(self) -> None:
        async with self._index_lock:
            files = self.files.list_memory_files()
            for f in files:
                await self._index_file(f)
            logger.info(f"全量重建完成，{len(files)} 个文件")

    async def _index_file(self, path: Path) -> None:
        async with self._index_lock:
            rel = self.files.rel(path)
            text = self.files.read(path)
            self.vdb.delete_file(rel)
            if not text.strip():
                return
            chunks = self.chunker.split(text, self.embedder.count_tokens)
            if not chunks:
                return
            embs = await self.embedder.embed(chunks)
            now = int(time.time())
            self.vdb.upsert(
                ids=[self.vdb.chunk_id(rel, i) for i in range(len(chunks))],
                embeddings=embs,
                texts=chunks,
                metas=[{"file": rel, "source": "openclaw", "timestamp": now} for _ in chunks],
            )

    def _refresh_inject(self) -> None:
        parts: list[str] = []
        for name in self.cfg.get("inject_files", ["MEMORY.md", "SOUL.md"]):
            p = self.workspace / name
            if p.is_file():
                content = p.read_text(encoding="utf-8", errors="ignore").strip()
                if content:
                    parts.append(f"## {name}\n{content}")
        self.inject_text = "\n\n".join(parts)

    async def _on_md_changed(self, path: Path) -> None:
        try:
            rel = self.files.rel(path)
        except ValueError:
            return
        if str(path).endswith((".md",)):
            if rel in [n for n in self.cfg.get("inject_files", [])]:
                self._refresh_inject()
            if self.files.list_memory_files() and path in self.files.list_memory_files():
                await self._index_file(path)
                logger.info(f"增量重建索引: {rel}")

    # ---------- system prompt 注入 ----------

    @on_llm_request()
    async def _inject(self, event: AstrMessageEvent, req: ProviderRequest) -> None:
        if not self.enabled or not self.inject_text:
            return
        sp = req.system_prompt or ""
        if INJECT_MARKER not in sp:
            req.system_prompt = sp + INJECT_MARKER + self.inject_text

    # ---------- 对话入库 ----------

    @on_agent_done()
    async def _on_conv_done(self, event: AstrMessageEvent, run_context, response) -> None:
        if not self.ingestor:
            return
        try:
            user_text = event.message_str or ""
            ai_text = getattr(response, "completion_text", "") or ""
            if user_text and ai_text:
                session_id = event.unified_msg_origin
                await self.ingestor.enqueue(session_id, user_text, ai_text)
        except Exception:
            logger.exception("对话入库入队失败")

    # ---------- LLM 工具 ----------

    @filter.llm_tool(name="memory_search")
    async def memory_search(
        self, event: AstrMessageEvent, query: str, source: str = "all", time_range: str = ""
    ) -> str:
        """搜索记忆库（OpenClaw 记忆文件 + 历史对话）。

        Args:
            query(string): 搜索关键词或自然语言描述
            source(string): 来源过滤，可选 all / openclaw / astrbot
            time_range(string): 时间范围，如 7d=最近7天、24h=最近24小时，留空不限
        """
        if not self.searcher:
            return "记忆库未初始化"
        hits = await self.searcher.search(query=query, source=source, time_range=time_range, top_k=5)
        if not hits:
            return "未找到相关记忆"
        return "\n---\n".join(
            f"[{h.source} | {h.file} | {time.strftime('%Y-%m-%d %H:%M', time.localtime(h.timestamp))} | score {h.score}]\n{h.text}"
            for h in hits
        )

    # ---------- 管理命令 ----------

    @filter.command("mem")
    async def mem_cmd(self, event: AstrMessageEvent, *args: str) -> None:
        sub = (args[0] if args else "status").strip().lower()
        if sub == "status":
            if not self.vdb:
                yield event.plain_result("记忆插件未启动（检查 enabled / workspace_path）")
                return
            yield event.plain_result(
                f"索引块数: {self.vdb.count()}\nworkspace: {self.workspace}\n注入文件: "
                f"{', '.join(self.cfg.get('inject_files', []))}\n注入文本长度: {len(self.inject_text)}"
            )
        elif sub == "rebuild":
            yield event.plain_result("重建中...")
            await self._reindex_all()
            self._refresh_inject()
            yield event.plain_result(f"重建完成，{self.vdb.count()} 块")
        elif sub == "test" and len(args) >= 2:
            q = " ".join(args[1:])
            hits = await self.searcher.search(query=q, top_k=3) if self.searcher else []
            if not hits:
                yield event.plain_result(f"「{q}」无结果")
                return
            for h in hits:
                yield event.plain_result(f"[{h.source} | {h.file} | {h.score}]\n{h.text[:200]}")
        else:
            yield event.plain_result("用法: /mem status | /mem rebuild | /mem test <关键词>")
```

> 注意 `import asyncio` 放文件顶部，上面 main.py 里的局部 import 是示意，实际写的时候顶部统一导入。

## 四、数据流

```
OpenClaw workspace/*.md
   │ 启动全量 / watcher 增量
   ▼
Chunker(384t±64t重叠) → Embedder(Qwen3-0.6B) → Chroma(source=openclaw)
                                                        ▲
AstrBot 对话 ── on_agent_done ── ConversationIngestor(异步队列) ──┘(source=astrbot)

LLM 请求 ── on_llm_request ── system_prompt 追加 MEMORY.md+SOUL.md
Agent  ── 调 memory_search 工具 ── Searcher(cosine top-k → 时间过滤 → 去重)
```

## 五、部署与验证

1. 插件目录放进 `data/plugins/`，依赖会自动 pip 安装（首次装 sentence-transformers + torch 较慢）
2. WebUI 启用插件，配置 `workspace_path`（填 OpenClaw workspace 绝对路径）
3. 等启动日志出现 `openclaw_memory 启动完成，索引 N 块`（首次下模型约 1.2GB，加载 1~3 分钟）
4. `/mem status` 确认索引数
5. `/mem test 你的关键词` 验证检索
6. 正常聊一轮，观察日志 `对话入库 N 块`
7. 改一下 MEMORY.md 保存，等 2 秒看日志 `增量重建索引`
8. 让 Agent 主动搜（问它"我之前记过什么"），确认 memory_search 被调用
9. WebUI 重载插件，确认 `data/plugin_data/.../chroma` 数据还在

## 六、资源与风险

| 项 | 说明 |
|---|---|
| 显存/内存 | 0.6B fp32 约 2.5GB。有 NVIDIA 卡就 auto 走 cuda，紧张就 `device: cpu`（0.6B CPU 推理单条 query 约 100~300ms，可接受） |
| 首次冷启动 | 下模型 + 全量索引，日志里明确打印进度，别以为挂了 |
| Chroma where 限制 | 只支持简单等值，时间范围后处理过滤，所以 query 时取 top_k*3 再截断 |
| on_agent_done 参数 | `run_context` 内部结构随版本变，v1 只用 `event.message_str + response.completion_text` 兜底，最稳 |
| watcher 防抖 | 2 秒 debounce 防编辑器写一半；VSCode 保存会触发 created+modified，按路径去重 |
| conversation 膨胀 | 每轮对话独立入库，长期跑块数会涨。v2 加定期压缩合并，v1 不管 |
| 并发索引 | `_index_lock` 串行化全量/增量重建，watcher 高频触发时任务会排队，debounce 已兜底大部分 |
